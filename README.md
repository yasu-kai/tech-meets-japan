# TECH MEETS JAPAN

Global technology, matched to Japan.

A neutral Japan Entry intelligence platform that helps Japanese companies discover and compare global technology vendors, while giving overseas technology companies a structured path into the Japanese market.

## Product pillars
- Curated company database
- Japan Fit scoring
- Problem / use-case search
- Independent editorial profiles
- Japan Entry Research
- Vendor listing / featured stories
- Introductions, partner search and future GTM support

## Editorial principle
Paid listings or sponsored features do not influence Japan Fit Score or editorial ranking.

## Local development

```bash
npm install
npm run dev
```

## Production
Built with Next.js App Router and designed for Vercel.
